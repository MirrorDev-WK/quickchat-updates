# Quick Chat Standalone

ส่วนเสริม Quick Chat F9 สำหรับ Ragnarok SEA v6 พร้อมตัวอัปเดตแบบ Command ของ MirrorDev-WK

**รุ่น 0.4.0 ยังอยู่ระหว่างเตรียมทดสอบในเกมจริง** ระบบแพ็ก ลายเซ็น และการดาวน์โหลดออนไลน์ผ่านการทดสอบแล้ว

## สำหรับผู้ใช้ครั้งแรก

1. ดาวน์โหลด [QuickChat-Standalone-0.4.0.zip](https://github.com/MirrorDev-WK/quickchat-updates/releases/download/v0.4.0/QuickChat-Standalone-0.4.0.zip) แล้วแตก ZIP
2. ปิดเกม Launcher และ patcher ที่เปิดอยู่
3. เปิด `QuickChat.cmd` หรือ `QuickChat-Command.exe` ไม่ต้องลง Python
4. หากเคยใช้ชุดรวม BetterRTNW + Quick Chat เก่า ให้เลือก **6 — Migrate** หนึ่งครั้งเพื่อคืนไฟล์ Main ให้ BetterRTNW
5. เลือก **1 — Install** เพื่อติดตั้ง Quick Chat แบบแยก ถ้าหาเกมไม่เจอ เลือก **4** แล้วใส่โฟลเดอร์ Launcher หรือ roworld

ในเกม ส่งข้อความในช่องที่ต้องการหนึ่งครั้ง แล้วปิดแชทและกด F9 เพื่อส่งซ้ำ ระบบจำข้อความกับช่องแยกตามตัวละคร ไม่มีข้อความส่งเริ่มต้น

## อัปเดตครั้งต่อไป

เลือก **2 — Update** ใน Command หรือเปิด `Update.cmd` โปรแกรมรับรุ่นล่าสุดจากผู้จัดชุด ตรวจลายเซ็น Ed25519 และ SHA-256 ก่อนติดตั้ง

ถ้าเกมยังเปิดอยู่ จะดาวน์โหลดและตรวจไฟล์เก็บไว้ก่อน ให้ปิดเกมแล้วเลือก **1 — Install** เพื่อติดตั้งรุ่นที่ดาวน์โหลดมา

- **3 — Uninstall:** ถอนเฉพาะ Quick Chat จากไฟล์สำรองที่ตรวจสอบแล้ว
- **5 — Check:** แสดงรุ่นที่มี รุ่นที่ติดตั้ง และแหล่งอัปเดต
- **0 — Exit:** ปิด Command ไม่ต้องเปิดค้างตอนเล่น

Quick Chat แบบแยกแก้เฉพาะไฟล์ ChatController ที่รองรับ ส่วน BetterRTNW ใช้ตัวอัปเดตเดิมต่อได้หลังย้ายออกจากชุดรวมเก่า การเปลี่ยนไฟล์แชทจากเกมอาจยังต้องให้ผู้จัดชุดเพิ่มรุ่นที่รองรับ โปรแกรมจะปฏิเสธไฟล์ที่ไม่รู้จัก

## ไฟล์ใน Releases

- `QuickChat-Standalone-0.4.0.zip`: ชุด Command สำหรับผู้ใช้ครั้งแรก
- `quickchat-0.4.0.zip` และ `channel.json`: ข้อมูลอัปเดตที่ Command ดาวน์โหลดเอง ไม่ใช่ตัวติดตั้งสำหรับดับเบิลคลิก

ตัวอัปเดตรับเฉพาะแพ็กที่ลงลายเซ็นด้วยกุญแจของผู้จัดชุด และไม่ดาวน์โหลด EXE ใหม่มารันเอง ไม่มี private signing key หรือ GitHub token รวมในชุดผู้ใช้

## ผลการตรวจรุ่นแรก

ผ่านการทดสอบออฟไลน์ 37 รายการ, Lua runtime แบบแยกของเกม, ไฟล์ ChatController ทั้ง 13 รุ่นที่รวมไว้ และการเปิด EXE โดยไม่มี Python ภายนอก การดาวน์โหลดจากแหล่ง GitHub จริงพร้อมตรวจลายเซ็นและแคชผ่านแล้ว ยังไม่มีการยืนยันการทำงานในเกมที่เปิดเล่นจริง
